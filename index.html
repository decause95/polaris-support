Soporte de Polaris

Polaris es una app para puntuar la temperatura de las cervezas y ayudar a enfriar las birras del mundo. Si tienes un problema, una duda o quieres pedir la eliminación de tu cuenta, estamos aquí para ayudarte.

Ayuda con la app

Abre una solicitud si necesitas ayuda con:

  • Inicio de sesión o creación de cuenta.
  • Problemas al valorar una cerveza.
  • Ubicación o selección de bares.
  • Errores en estadísticas o rankings.

Cuenta y datos

Puedes pedir ayuda para eliminar tu cuenta o tus datos desde una solicitud de soporte. No incluyas contraseñas, códigos de verificación ni información sensible.

Privacidad

Polaris usa tu ubicación solo cuando la autorizas, para sugerirte bares cercanos al crear una valoración. Las solicitudes de privacidad también se gestionan desde soporte.

Estado

Si detectas un fallo, describe que estabas intentando hacer, el dispositivo que usas y cualquier mensaje de error que aparezca.
