Política de privacidad

Polaris es una app para puntuar la temperatura de las cervezas y ayudar a enfriar las birras del mundo. Esta política explica qué datos se tratan al usar la app, para qué se usan y cómo puedes solicitar ayuda.

Datos de cuenta

Para guardar valoraciones, Polaris usa Clerk como proveedor de autenticación. Puedes iniciar sesión con Apple, Google o email y contraseña. Polaris puede tratar el identificador de usuario de Clerk, tu nombre visible, avatar y dirección de email cuando esos datos están disponibles en tu cuenta.

Estos datos se usan para iniciar sesión, mostrar tu perfil, vincular tus valoraciones a tu cuenta y permitir la eliminación de cuenta desde la app. Polaris no guarda contraseñas ni tokens de sesión en su base de datos.

Valoraciones y locales

Al enviar una valoración, Polaris guarda la marca de cerveza elegida, si es de botella o de barril, la puntuación de frío, la fecha de la valoración y el local seleccionado. Del local se conserva el identificador de origen, nombre, dirección disponible, localidad, categorías y coordenadas.

Si el local procede de Geoapify, las coordenadas describen el establecimiento seleccionado. Si lo añades manualmente, proceden de tu ubicación actual redondeada a cuatro decimales. En ese caso, al guardar una valoración, el nombre y las coordenadas del local quedan almacenados y vinculados a tu cuenta; pueden aproximar el lugar desde el que lo añadiste.

Ubicación opcional

Polaris solo solicita tu ubicación cuando pulsas la acción para buscar locales cercanos o para añadir un local manualmente. Si concedes permiso para la búsqueda, la app obtiene una ubicación actual y la envía a la API de Polaris para sugerir bares, restaurantes, pubs o cafeterías cercanos mediante Geoapify.

Si no encontramos el local y pulsas Añadir este local, la app envía a la API su nombre y una ubicación actual. Polaris crea el local sin enviar esa petición a Geoapify. La ubicación del local solo se conserva en la base de datos cuando guardas una valoración de él. La app no solicita ubicación en segundo plano ni hace seguimiento continuo. También puedes buscar locales escribiendo el nombre sin conceder permiso de ubicación.

Identificador técnico de instalación

Polaris genera un identificador aleatorio de instalación y lo guarda en el dispositivo. Se envía a la API para aplicar límites de uso y proteger el servicio frente a abuso. No se usa para publicidad ni para seguimiento entre apps o sitios web.

Proveedores

Polaris utiliza estos proveedores para operar la app:

  • Clerk, para autenticación y gestión de cuentas.
  • Cloudflare Workers, para ejecutar la API de Polaris y aplicar límites de uso.
  • Neon, para almacenar valoraciones, locales y datos mínimos de cuenta.
  • Geoapify, para buscar locales y sugerir resultados cercanos cuando usas la ubicación o una búsqueda.
  • Apple y Google, cuando eliges iniciar sesión con esos proveedores.

Finalidades

Los datos se usan para:

  • crear y mantener tu cuenta;
  • guardar y mostrar tus valoraciones;
  • buscar locales y sugerir resultados cercanos;
  • mostrar estadísticas y rankings agregados;
  • prevenir abuso, duplicados y uso excesivo de la API;
  • diagnosticar errores y mantener el servicio.

Sin tracking publicitario

Polaris no vende datos personales, no muestra anuncios y no utiliza tus datos para tracking publicitario entre apps o sitios web de otras empresas.

Eliminación de cuenta y datos

Puedes eliminar tu cuenta desde la app, en el perfil de usuario. Esa acción solicita la eliminación de tu perfil de Polaris, tus valoraciones asociadas y la cuenta de identidad gestionada por Clerk.

Si necesitas ayuda adicional, abre una solicitud en soporte de Polaris. No incluyas contraseñas, códigos de verificación ni información sensible en la solicitud.
